# CCOJ Web

CCOJ 微服务版的 Vue 前端。需要 Node.js 22.18+（22.x）或 24.12+。

## 本地联调

1. 启动 CCOJ 网关（8080）、用户服务和题目服务。要验证判题结果，再启动 RabbitMQ、判题服务和沙箱。后端启动参数参见 CCOJ 微服务工程的 README。
2. 在前端目录运行 `npm install` 和 `npm run dev`，打开终端显示的地址。
3. 使用已有账号登录，或者通过登录页注册。使用 Knife4j 以管理员身份创建并发布一道 Java 题，再进入题库提交代码。
4. 提交后页面会自动查询结果。测试正确答案、错误答案和编译失败，并刷新页面检查会话能否恢复。

Vite 将 `/api/**` 去掉 `/api` 前缀后转给 `http://localhost:8080`。浏览器会自动发送同源 Session Cookie。开发期间统一使用同一浏览器地址。

`npm run build` 会检查类型并生成 `dist`。部署静态文件时，Web 服务器需要将页面地址回退到 `index.html`，并把 `/api/**` 去掉前缀后代理到网关。
